# PG Rocket 🚀

A fast, lightweight PostgreSQL client for Node. 🚀

## Try it locally

```sh
pnpm db:up
pnpm example
```

The example creates a small `rocket_demo.todos` table in the bundled local
Postgres and exercises queries, SQL helpers, transactions, and cursors. See
[`packages/example`](packages/example) for the source.
